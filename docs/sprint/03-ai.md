## 1. Quyết định kiến trúc (ngày 1)

### 1.1. Chọn I-feature chính cho demo 10 phút

Đề OLP 2026 yêu cầu ≥ 1 chức năng I. Đề HaUI ưu tiên "AI/ML có giá trị thực tế, có đánh giá và căn cứ; không sử dụng AI chỉ để trang trí".

| I-feature | Giá trị demo | Khả thi 14 ngày | Đánh giá |
|---|---|---|---|
| **1. Phân loại ticket** (rule + LLM fallback) | ⭐⭐⭐ | ✅ Đã có, làm đẹp | **Làm, nhưng đừng dừng ở đây** |
| **2. Gợi ý KTV** (rule + match) | ⭐⭐⭐ | ✅ Đã có, nâng cấp | **Làm** |
| **3. AI gợi ý giải pháp** (RAG trên KB) | ⭐⭐⭐⭐⭐ | ⚠️ Trung bình | **Làm — đây là I-feature ăn điểm** |
| **4. Phát hiện ticket trùng lặp** (semantic search) | ⭐⭐⭐⭐ | ⚠️ Trung bình | Làm nếu còn time |
| **5. Dự báo SLA breach** (rule + LLM) | ⭐⭐⭐ | ⚠️ Trung bình | Làm nếu còn time |
| **6. Auto-tóm tắt ticket** (LLM) | ⭐⭐⭐ | ✅ Dễ | Làm nếu còn time |

**Đề xuất của tôi**: làm **1, 2, 3** là bộ tối thiểu "ăn điểm". Nếu còn time làm **4, 6**.

### 1.2. Stack quyết định

| Mục | Chọn | Lý do |
|---|---|---|
| LLM | **Ollama `llama3.2:3b`** (đã có config) | Nhẹ, chạy local, OSI-friendly |
| Embedding | **`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`** | Hỗ trợ tiếng Việt, ~50MB, MIT license |
| Vector store | **Qdrant** (in-memory hoặc file-backed) | Open-core phù hợp, dễ Docker, có client Python |
| Orchestration | **LangChain** hoặc viết tay | Viết tay để demo được (transparency) |
| Fallback khi Ollama offline | **Rule-based** (đã có) | Đề yêu cầu "không bắt buộc LLM" |

**Quyết định: KHÔNG dùng LangChain, viết tay** vì:
- Nhẹ hơn (giảm attack surface PoF).
- Dễ debug khi demo.
- Code rõ ràng cho hội đồng đọc.

### 4.2. Eval script (`scripts/run_eval.py`)

```python
# Chạy: python -m scripts.run_eval
# Output: reports/eval-2026-XX-XX.md

import json, asyncio
from app.services.classifier import classify

async def main():
    cases = json.load(open("app/data/eval/classify_eval.json"))
    correct = 0
    for c in cases:
        result = await classify(c["title"], c.get("description", ""))
        if result["category"] == c["expected_category"]:
            correct += 1
    print(f"Accuracy: {correct}/{len(cases)} = {correct/len(cases)*100:.1f}%")
```

## 8. Câu hỏi hội đồng thường hỏi — tôi sẵn sàng trả lời

Từ đề HaUI section 13: "AI/ML được dùng ở đâu? Dữ liệu đầu vào, mô hình, đánh giá và giới hạn của kết quả là gì?"

Câu trả lời mẫu:
> "AI dùng ở 5 chỗ: phân loại ticket, ưu tiên, gợi ý KTV, tìm giải pháp (RAG), tìm ticket trùng. Dữ liệu đầu vào là tiếng Việt từ sinh viên/nhân viên.
